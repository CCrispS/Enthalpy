# Enthalpy v1.0.1

修复版：`GhostOpacity` 的透明度梯度终于按定义工作（0/1/2/3/4 = 0/25/50/75/100 %），并且剪影不再随帧数累积叠色、脚下方地面也会逐帧重绘，地形能真正透出来。

RA3-style formation orders for **Command & Conquer: Yuri's Revenge 1.001** — hold the middle mouse button at the destination, drag to shape the block, release to move and turn every selected unit exactly where the translucent silhouettes were shown.

## 本版修复 / Fixed in this release

- **透明度梯度是线性的**：剪影本体改用 `Blend565(under, colour, opacity)`，不再按地形亮度预乘色值。此前 `BlendGhost565()` 会把绿色压向背景，导致 1/2/3 档几乎看不出差别；现在 0 = 完全不可见、1 = 25 %、2 = 50 %、3 = 75 %、4 = 完全不透明。
- **每帧只混合一次**：渲染钩子 `0x6D9134` 每帧会被调用 3–5 次，旧实现每次调用都叠一层，25 % 的剪影被复合到约 76 %，看起来“调了没用”。现在 `DrawPreview()` 入口用 QPC 做 10 ms 去重，一帧只画一次。
- **脚下方地面逐帧重绘**：引擎的脏矩形优化不会重绘剪影覆盖过的地面，导致每帧都在上一帧的剪影上再叠一层。现在绘制前用 `TacticalClass::RegisterDirtyArea()` 标记该矩形，地形能正常透出，颜色也不会随时间漂移。
- **描边规则**：轮廓始终 100 % 不透明（不随 `GhostOpacity` 变淡），并在 `GhostOpacity=4`（完全不透明）时**完全不画**，避免满不透明时多出一圈亮边。
- **文档**：新增 `docs/RELEASING.md`，把“所有改动走 PR、发布必须同时给源码与二进制”的协作方式写进仓库；`CONTRIBUTING.md` 与 `README.md` 同步更新。

## 安装 / Install

1. 把 `Enthalpy.dll` 和 `Enthalpy.ini` 放进游戏根目录（与 `gamemd.exe` 同级）。
2. 用 Syringe / SyringeEx 加载：`Syringe.exe -i=Enthalpy.dll gamemd.exe`，或在 `Resources\ClientDefinitions.ini` 的 `ExtraCommandLineParams` 里追加 `-i=Enthalpy.dll`，或直接让 SyringeEx 的 `*.dll` 扫描自动识别。
3. 进入游戏，左键选中单位 → 在目的地按住中键拖动 → 松手。

## 升级说明 / Upgrade notes

- 直接覆盖旧的 `Enthalpy.dll` 即可；`Enthalpy.ini` 若有自定义键请保留原文件。
- `GhostOpacity` 的观感与 v1.0.0 不同（旧版因为叠色与预乘，实际比设定值更实），建议重新挑一个档位。

## 要求 / Requirements

- Yuri's Revenge 1.001（`gamemd.exe` 标准版），32 位。
- Syringe 0.7.x 或 SyringeEx 0.1.x。
- 可选：Ares 3.0p1、Phobos（本插件不依赖其内部结构，但会与其共存）。
- 构建：Visual Studio 2022+，Win32，`Enthalpy.vcxproj`（Release 默认 `/MT`，无 VC 运行库依赖）。

## 已知限制 / Known limitations

- 剪影是“借引擎画一遍再取差集”得到的位图，按 `(类型, 朝向档, 斜坡格)` 缓存；极端视角下某些朝向的体素剪影会偏窄。
- 剪影绘制在物体层之前，因此当预览格上正好站着单位时，会被该单位盖住（更晚的绘制点在当前引擎里没有可用且未被占用的 hook）。
- 飞行单位的剪影高度取 `RulesClass` 的 `FlightLevel` / `CruiseHeight` / `HoverHeight` 估算，悬停时可能与实际绘制略有差异。
- 步兵剪影固定用“就绪帧”，不跟随行走动画。
