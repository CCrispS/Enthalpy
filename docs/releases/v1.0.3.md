# Enthalpy v1.0.3

热修版（hotfix）：**展开基地车不再崩溃**。v1.0.2 的四项修复全部包含在内。

RA3-style formation orders for **Command & Conquer: Yuri's Revenge 1.001** — hold the middle mouse button at the destination, drag to shape the block, release to move and turn every selected unit exactly where the translucent silhouettes were shown.

## 本版修复 / Fixed in this release

- **展开基地车（MCV）时弹窗崩溃**：引擎展开 MCV 时会把 `UnitClass` 替换成 `BuildingClass`，原对象随即释放；而插件里 `units_[]` / `pending_[]` 保存的仍是旧指针。`DrawPreview()` 对它做虚调用时，vtable 已被清零，于是出现 `C0000005 at 00000000`、`EIP = 0`（崩溃前栈顶返回地址落在 `DrawPreview()+0x114`）。
  - `Update()` 每帧开头新增 `PruneDead()`：逐个确认 `units_[i]` 仍在 `TechnoClass::Array` 里；一旦发现单位消失，就把本次列队手势整体撤销（清空槽位/朝向待办/抑制计数），并记录 `units: N unit(s) disappeared mid-gesture`，避免槽位与单位错位。
  - `DrawPreview()` 的飞行朝向固定循环：先判 `IsAlive(item.Unit)`，已死则把该条待办标记为已应用并跳过。
  - `DrawPreview()` 的剪影循环：把存活判定提到 `GetTechnoType()` / `WhatAmI()` 之前。
- 其余行为与 v1.0.2 完全一致（剪影显示、缓存、透明度、朝向、Stop 定格、性能优化均未改动）。

## 安装 / Install

1. 把 `Enthalpy.dll` 和 `Enthalpy.ini` 放进游戏根目录（与 `gamemd.exe` 同级）。
2. 由 Syringe / SyringeEx 加载：`Syringe.exe -i=Enthalpy.dll gamemd.exe`，或在 `Resources\ClientDefinitions.ini` 的 `ExtraCommandLineParams` 里追加 `-i=Enthalpy.dll`，或让 SyringeEx 的 `*.dll` 扫描自动识别。
3. 进入游戏：左键选中单位 → 在目的地**按住中键**拖动 → 松手。

## 升级说明 / Upgrade notes

- 从 v1.0.2 升级：直接覆盖 `Enthalpy.dll` 即可，配置无需改动。
- 如需排查问题，把 `Enthalpy.ini` 里的 `Enthalpydebug` 改成 `yes`；若出现弹窗，请一并提供 `debug\snapshot-*\` 目录（含 `except.txt`）。

## 要求 / Requirements

- Yuri's Revenge 1.001（`gamemd.exe` 标准版），32 位。
- Syringe 0.7.x 或 SyringeEx 0.1.x。
- 可选：Ares 3.0p1、Phobos（本插件不依赖其内部结构，但会与其共存）。
- 构建：Visual Studio 2022+，Win32，`Enthalpy.vcxproj`（Release 默认 `/MT`，无 VC 运行库依赖）。

## 已知限制 / Known limitations

- 剪影是"借引擎画一遍再取差集"得到的位图，按 `(类型, 朝向档, 斜坡格)` 缓存；极端视角下某些朝向的体素剪影会偏窄。
- 剪影绘制在物体层之前：预览格上正好站着单位时会被该单位盖住（引擎里更晚且未被占用的 hook 目前没有）。
- 飞行单位的剪影高度取 `RulesClass` 的 `FlightLevel` / `CruiseHeight` / `HoverHeight` 估算，悬停时可能与实际绘制略有差异。
- 步兵剪影固定用"就绪帧"，不跟随行走动画。
