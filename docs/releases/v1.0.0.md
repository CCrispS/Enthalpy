# Enthalpy v1.0.0

RA3-style formation orders for **Command & Conquer: Yuri's Revenge 1.001** — hold the middle mouse button at the destination, drag to shape the block, release to move and turn every selected unit exactly where the translucent silhouettes were shown.

## 功能 / Features

- **中键手势**：左键选中单位后，在目的地按住鼠标中键即进入列队模式；移动光标决定朝向与间距，松开中键下达指令。
- **真实剪影预览**：每个目标格画出该单位**当前朝向的真实图像**（体素走 `DrawAsVXL`，SHP 走像素质心剪影），带影子、可调透明度与颜色，非法格转红并吸附到最近合法格。
- **格位精确**：按 `CellClass` 占格——一辆载具一格，步兵一格最多 3 人，格内站位由引擎的 `FindInfantrySubposition` 决定。
- **地形与水面**：剪影使用目的地格自身的三维坐标（含层高与桥面），斜坡按坡面倾斜；水面/陆地合法性按单位的 `SpeedType` 判定（船只只走水、两栖两者皆可）。
- **落位与朝向**：到位后原地转向预览朝向，然后自动 `Stop` 钉住，不再自行走回出发地；玩家点击即可接管。
- **飞行单位**：剪影悬停在对应高度，地面用椭圆影子标示落点格。
- **纯 ini 配置**：DLL 同级 `Enthalpy.ini`，改完下一轮手势即生效，无需重启。

## 安装 / Install

1. 把 `Enthalpy.dll` 和 `Enthalpy.ini` 放进游戏根目录（与 `gamemd.exe` 同级）。
2. 用 Syringe / SyringeEx 加载：`Syringe.exe -i=Enthalpy.dll gamemd.exe`，或在 `Resources\ClientDefinitions.ini` 的 `ExtraCommandLineParams` 里追加 `-i=Enthalpy.dll`，或直接让 SyringeEx 的 `*.dll` 扫描自动识别。
3. 进入游戏，左键选中单位 → 在目的地按住中键拖动 → 松手。

## 要求 / Requirements

- Yuri's Revenge 1.001（`gamemd.exe` 标准版），32 位。
- Syringe 0.7.x 或 SyringeEx 0.1.x。
- 可选：Ares 3.0p1、Phobos（本插件不依赖其内部结构，但会与其共存）。
- 构建：Visual Studio 2022+，Win32，`Enthalpy.vcxproj`（Release 默认 `/MT`，无 VC 运行库依赖）。

## 已知限制 / Known limitations

- 剪影是“借引擎画一遍再取差集”得到的位图，按 `(类型, 朝向档, 斜坡格)` 缓存；极端视角下某些朝向的体素剪影会偏窄。
- 飞行单位的剪影高度取 `RulesClass` 的 `FlightLevel` / `CruiseHeight` / `HoverHeight` 估算，悬停时可能与实际绘制略有差异。
- 步兵剪影固定用“就绪帧”，不跟随行走动画。
